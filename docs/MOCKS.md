# Mock adaptörler ve sahte veri kaynakları (MOCKS)

Biçim: Ek C-8. Üretim derlemesinde MOCK yasaktır (§12.8).

_Faz 0 itibarıyla MOCK adaptör yoktur._ İlk MOCK'lar Faz 1 dilim 8'de (dış entegrasyon portları: konaklama fiyat/müsaitlik, araç kiralama, harita) eklenecek ve burada M-001'den itibaren kaydedilecek.
