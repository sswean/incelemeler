# Araştırma notları (v1 → v2)

Bu klasör, v2 promptu hazırlanırken v1'in uzman merceklerinden (prompt mühendisliği, ürün/UX, mimari/veri, Türk hukuku/mağaza politikaları) geçirildiği ham analiz notlarını içerir.

- Bunlar **çalışma notlarıdır**, talimat değildir. Ajana verilecek metin `prompts/INCELEMELER-MASTER-PROMPT-v2.md` dosyasıdır.
- Notlardaki her bulgu "doğrulandı: evet/hayır" alanı taşır. "hayır" olan dış olgular (özellikle 2024–2026 Türk mevzuatı değişiklikleri) ikincil kaynaklardan derlenmiştir ve hukuki doğrulama gerektirir.
- SEO, güven/moderasyon, gelir/reklam, mobil, DevOps/güvenlik ve tasarım/marka mercekleri v2 metnine doğrudan işlenmiştir; ayrı not dosyaları yoktur.
